# DŪON

A modern web application built with React, TypeScript, and cutting-edge web technologies. DŪON showcases minimal design principles with a focus on clean aesthetics and smooth user experience.

## 🚀 Tech Stack

- **React 18+** - Modern React with latest features
- **TypeScript** - Type-safe development
- **Vite** - Lightning-fast build tool and dev server
- **TanStack Router** - Type-safe file-based routing
- **Tailwind CSS** - Utility-first styling framework
- **Framer Motion** - Smooth animations and transitions
- **Custom Theme System** - Dark/light mode with smooth transitions

## ✨ Features

- **Modern Design** - Clean, minimal interface with beautiful typography
- **Theme Toggle** - Custom dark/light mode switcher with animated transitions
- **Responsive Layout** - Mobile-first design that works on all devices
- **Smooth Animations** - Framer Motion powered animations and page transitions
- **Type Safety** - Full TypeScript coverage with TanStack Router
- **Performance Optimized** - Fast loading and smooth interactions

## 🛠️ Development

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Getting Started

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start development server**

   ```bash
   npm run dev
   ```

3. **Build for production**

   ```bash
   npm run build
   ```

4. **Preview production build**
   ```bash
   npm run preview
   ```

### Project Structure

```
src/
```
